# Planning

## Overview
**App Name:** ProFresh  
**Description:** ProFresh is a task tracker that keeps your todo list fresh. It saves your tasks with a priority and a due date, and it also remembers the last time you touched each task, so if one task is not updated for a long time, the app marks it as "stale" and you can see which task you forgot.

## Features

### Essential

**Adding Tasks to Task List**  
The user give a title, a priority (low/medium/high), and a due date.

**Listing Tasks from Task List**  
The user can filter them and sort them by due date, or by priority.  Old tasks are shown with a "stale mark.

**Marking Tasks as Complete**  
When a task is completed the finish time will be recorded.

**Deleting Tasks from Task List**  
The user can delete tasks when they are complete or if the task is no longer needed.

**Editing Tasks in Task List**  
The user can change the title, the priority, or the due date.  After an edit the task becomes fresh again.

**Saving to JSON File**  
The app saves all the tasks into a JSON file and load them again, so the tasks are still there next time the user opens the app.

### Optional

**Adding Tags to Tasks in Task List**  
The user can add tags to a task, then the user can group and filter the tasks by tag.

**Sorting Tasks in Task List**  
The user can sort tasks by due date

**Filter Tasks in Task List**  
The user can filter tasks by tags
